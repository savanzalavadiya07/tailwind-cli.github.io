Basic Git Commands => git --version
Check Git version installed => git init
Initialize a new Git repository => git clone <repository-url>
Working with Files => git status
Check file status => git add <file-name>
                    git add .
Add file(s) to staging area => git commit -m "commit message"
Branching => git branch
List branches => git branch <branch-name>
Create a new branch => git checkout <branch-name>
Switch branches => git checkout -b <branch-name>
Remote Repository => git remote -v
Check remote repository => git push origin <branch-name>
